# COIPO_PRENSA — Monitor de Prensa CONAF

Aplicación web estática que muestra las últimas noticias de medios chilenos donde se
menciona **CONAF** / **Corporación Nacional Forestal**, al estilo del boletín de prensa
diario. Reemplaza un servicio pagado de clipping con infraestructura 100% gratuita
(GitHub Pages + GitHub Actions).

> 🚧 En construcción. Documentación completa al cierre de la v1.

- Recolector de noticias (Node, arquitectura hexagonal): [collector/](collector/)
